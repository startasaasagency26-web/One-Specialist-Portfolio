# Codex Handoff Template

Use this structure when handing the plan to a coding agent.

## Build objective
State the site type, desired mood, target user, and conversion goal.

## Non-negotiables
List the required stack, page structure, output files, and constraints.

## Visual direction
Describe the reference style in principles, not brand copying.

## Page map
List all pages or single-page sections in order.

## Section implementation notes
For each section specify:
- layout intent
- content blocks
- motion behavior
- whether it needs client-side interactivity
- whether it uses 3d

## Technical rules
Specify:
- responsive behavior expectations
- reduced motion handling
- image/video optimization expectations
- component organization
- content organization

## Deliverables
Require:
- full code
- README
- animation notes
- QA checklist
- deployment steps
