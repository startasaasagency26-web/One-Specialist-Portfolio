# Codex Site Copy Assembler

This skill turns messy input into clean, premium website copy.

## Core rules

- Write with restraint.
- Be concrete before clever.
- Use short sentences unless detail is necessary.
- Never invent facts, names, numbers, certifications, case studies, or guarantees.
- If information is missing, write flexible copy that stays truthful.
- Separate **verified facts** from **visual assumptions** inferred from references.

## Apple-style copy interpretation

When the brief calls for an apple-style feel, aim for:

- calm authority
- sharp phrasing
- minimal filler
- clear benefit framing
- premium tone without sounding like a tech parody

Avoid:

- startup cliches
- hype language
- "revolutionary," "cutting-edge," and other empty claims
- walls of text
- trying too hard to sound futuristic

## Workflow

1. Extract usable facts
   Pull out:
   - company name
   - what it does
   - who it serves
   - service list
   - differentiators
   - trust indicators
   - CTA destination

2. Decide the content depth
   - thin brief → concise portfolio copy
   - detailed brief → richer section copy and metadata

3. Build the messaging ladder
   Use this order:
   - headline promise
   - supporting clarity
   - capability proof
   - process confidence
   - conversion close

4. Write by section
   Draft only what the layout can support. Do not write five paragraphs for a section designed to hold one sentence.

5. Tighten aggressively
   Remove vague adjectives and duplicated ideas.

## Default section copy set

For a company portfolio website, prepare copy for:

- hero
- about/intro
- services/capabilities
- showcase or proof
- process
- faq or trust layer
- closing CTA
- footer microcopy
- SEO title and meta description

## Tone calibration rules

### Better patterns
- name the outcome
- name the audience
- name the process or standard
- sound composed

### Worse patterns
- overpromising
- self-congratulatory language
- using trendy jargon instead of meaning
- long intros that delay the point

## Output format

# Website copy deck

## 1. brand voice summary
- tone
- positioning
- phrases to lean into
- phrases to avoid

## 2. hero copy
- headline options
- supporting line options
- primary CTA
- secondary CTA if needed

## 3. section copy
For each section include:
- heading
- subheading or intro
- body copy
- labels or card copy where needed

## 4. service blurbs
- service name
- one-line descriptor
- optional supporting line

## 5. trust and faq
- trust statements
- faq questions and answers if appropriate

## 6. seo copy
- page title
- meta description
- open graph line if helpful

## 7. microcopy
- nav labels
- form labels
- CTA variants
