# Motion Rules

## Strong default patterns

### Hero
- slow intro fade/translate
- subtle media scale shift
- restrained headline stagger
- optional object drift or camera settle

### Section reveal
- fade + translate + blur reduction
- stagger only when the content is clearly grouped
- one dominant motion direction per section

### Sticky narrative block
- pin a section only when the user needs time to absorb a transformation
- animate progress clearly from state A to B

### CTA section
- keep motion lighter here
- conversion sections should feel stable and trustworthy

## Anti-patterns

- every section animates from a different direction
- huge overshoots and elastic motion on premium brands
- background effects that compete with the main message
- text moving so much that it becomes harder to read
- delays on critical interactions just to look cinematic
- infinite floating on every card

## Good motion hierarchy

1. section transition
2. key focal element
3. supporting text
4. decorative layer

Decorative layers should always be the weakest signal.
